	%%%%%%%%%%%%%%%%%%%% Introduction %%%%%%%%%%%%%%%%%%%%
	
	\chapter{Introduction}
	
	Attendance monitoring is an essential activity in educational institutions. Traditional attendance systems are time-consuming and prone to human error. Artificial Intelligence provides an automated solution using computer vision.
	
	\section{Problem Statement}
	
	Manual attendance:
	\begin{itemize}
		\item Takes time.
		\item Can contain errors.
		\item Allows proxy attendance.
	\end{itemize}
	
	%%%%%%%%%%%%%%%%%%%% Objectives %%%%%%%%%%%%%%%%%%%%
	
	\chapter{Objectives}
	
	The objectives of this project are:
	
	\begin{enumerate}
		\item Automate attendance using facial recognition.
		\item Reduce proxy attendance.
		\item Generate attendance reports automatically.
		\item Store records securely in a database.
	\end{enumerate}
