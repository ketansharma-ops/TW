# References and Learning Resources

This file collects official documentation and class resources used while studying the topics in this repository.

## 1. Git and GitHub

- [Git Documentation](https://git-scm.com/doc) — official Git reference.
- [Pro Git Book](https://git-scm.com/book/en/v2) — explanations of Git concepts and workflows.
- [GitHub Docs](https://docs.github.com/) — repositories, branches, commits and collaboration.

## 2. LaTeX

- [LaTeX Project](https://www.latex-project.org/) — information about the LaTeX system.
- [Overleaf Learn LaTeX](https://www.overleaf.com/learn) — tutorials and examples.
- [CTAN](https://ctan.org/) — packages and documentation for TeX and LaTeX.

## 3. Doxygen

- [Doxygen Manual](https://www.doxygen.nl/manual/) — configuration, comments and output generation.
- [Doxygen Commands](https://www.doxygen.nl/manual/commands.html) — commands such as `@brief`, `@param` and `@return`.

## 4. Google Docs

- [Google Docs Help](https://support.google.com/docs/) — document creation, formatting and collaboration.
- [Google Drive Help](https://support.google.com/drive/) — file storage and organisation.

- Technical Writing lecture slides.

## 6. Referencing Practice

When using external material:
- Prefer official documentation.
- Record the title and source URL.
- Cite quoted or paraphrased information.
- Do not present copied material as original work.
- Check links before submission.

This is a navigation list of learning resources, not a substitute for formal citations in individual assignments.
