# Google Docs

## 1. Introduction

### What is Google Docs?
Google Docs is an online word processor used to create, edit, format and share documents.

### What is it used for?
- Writing reports and assignments.
- Preparing collaborative documents.
- Reviewing and commenting on content.
- Sharing documents with selected users.

### How is it different from an offline word processor?
Google Docs supports cloud storage and real-time collaboration. Multiple authorised users can work on the same document.

## 2. Creating and Organising Documents

### How do I create a document?
Create a blank document or use a template through Google Docs or Google Drive.

### Why use meaningful file names?
Clear names make documents easier to identify, search and organise.

### How can documents be organised?
Store related files in Drive folders grouped by subject, project or assignment.

## 3. Formatting

### Why is formatting important?
Consistent formatting improves readability and makes the structure clear.

### What are paragraph styles?
Styles such as Title, Subtitle, Heading 1 and Heading 2 apply consistent formatting and establish hierarchy.

### Why use heading styles?
- They organise long documents.
- They support navigation.
- They help generate a table of contents.

### Which formatting options are commonly used?
- Font family and size.
- Bold, italic and underline.
- Text and highlight colour.
- Alignment and line spacing.
- Bulleted and numbered lists.
- Indentation and paragraph spacing.

## 4. Page Structure

### How can page layout be controlled?
Page setup options control orientation, paper size and margins.

### What are headers and footers?
They place repeated information, such as document titles or page numbers, in consistent page locations.

### How can page numbers be inserted?
Use the Insert menu and choose the page-number option.

### What is a table of contents?
It lists document headings and helps readers navigate a long document. Heading styles should be applied consistently.

## 5. Collaboration

### What is real-time collaboration?
Multiple authorised users can edit a document and see updates as they occur.

### What are sharing permissions?

| Role | Permission |
|---|---|
| Viewer | View the document |
| Commenter | View and add comments |
| Editor | Modify the document |

### What is commenting?
Comments allow reviewers to provide feedback without directly changing the main text.

### What is Suggesting mode?
It proposes edits that can be reviewed and accepted or rejected.

## 6. Version History

### What is version history?
It records earlier states of a document and helps users inspect or restore previous versions.

### Why is it useful?
- Tracks document changes.
- Helps recover earlier content.
- Supports review of collaborative edits.

## 7. Document Review

### What should be checked before submission?
- Correct title and headings.
- Consistent fonts and spacing.
- Page numbering.
- Tables and figures.
- Spelling and grammar.
- Links and references.
- Sharing permissions.

### Why export as PDF?
PDF helps preserve layout across devices and is commonly used for final submissions.

## 8. Practical Workflow

1. Create and name the document.
2. Organise content using heading styles.
3. Format paragraphs, lists and tables consistently.
4. Add page numbers and a table of contents if needed.
5. Share with appropriate permissions.
6. Review comments and suggestions.
7. Check the final layout.
8. Export as PDF when required.

## Key Takeaways

- Google Docs is a cloud-based word processor.
- Heading styles provide document structure.
- Sharing roles control access.
- Comments and Suggesting mode support review.
- Version history helps track and restore changes.
- PDF export is useful for final distribution.
