\doxysubsection{Detailed Description}
Performs mathematical calculations. 

The \doxylink{class_calculation_engine}{Calculation\+Engine} class provides mathematical operations and uses the \doxylink{class_logger}{Logger} class to display calculation information.

Currently, it supports power calculation using a base and an integer exponent.
